# K-th minheap

## Идея

Храним `k` наибольших значений из уже просмотренной части массива в
minheap. Корень кучи содержит минимум среди этих значений. Когда
просмотрен весь массив, этот минимум и есть `k`-й элемент по величине.
Одинаковые значения учитываются столько раз, сколько встречаются.

## Исполнение

Строим кучу из копии первых `k` элементов. Если следующее значение
больше корня, заменяем им корень и восстанавливаем свойство кучи.
Меньшее или равное значение можно пропустить, поскольку уже есть
`k` элементов не меньше него. В обоих случаях после шага куча по-прежнему
содержит `k` наибольших значений просмотренного префикса.

`kth_largest` использует `makeheap` и `sift_down` из первой задачи.
`kth_largest_heapq` выполняет те же операции через `heapify` и
`heapreplace`. Обе функции сохраняют исходный список и поднимают
`ValueError`, если `k` вне диапазона от 1 до длины массива.

## Визуализация

Для массива `[3, 2, 1, 5, 6, 4]` и `k = 2` обе реализации проходят
следующие состояния.

| Шаг | Действие | Куча |
| --- | --- | --- |
| Первые два элемента | Построить кучу из `[3, 2]` | `[2, 3]` |
| 1 | Пропустить, поскольку `1 < 2` | `[2, 3]` |
| 5 | Заменить 2, просеять 5 вниз | `[3, 5]` |
| 6 | Заменить 3, просеять 6 вниз | `[5, 6]` |
| 4 | Пропустить, поскольку `4 < 5` | `[5, 6]` |

Корень `5` является вторым наибольшим элементом.

## Сложность

Построение кучи занимает `O(k)` времени. Просмотр остальных `n - k`
элементов требует по одному сравнению, а замена корня занимает
`O(log k)) при `k ≥ 2`. Итого время в худшем случае составляет
`O(k + (n - k)(1 + log k))`. При `k = 1` выполняется линейный поиск
максимума за `O(n)`. Дополнительная память составляет `O(k)).

## Тесты

`test_k_th_minheap.py` проверяет обе реализации на примерах из условия,
отрицательных и одинаковых значениях, граничных и недопустимых рангах.
Для перемешанного массива с повторами проверяются все допустимые ранги.
