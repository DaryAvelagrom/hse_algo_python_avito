# Two Sum

## Идея

Нужно найти два разных элемента массива, сумма которых равна заданному числу.

Для каждого текущего элемента можно сразу понять, какое число должно быть вторым, если вычесть текущее число из заданного.

Если такое число уже встречалось раньше, то нужная пара найдена.

Чтобы быстро проверять, встречалось ли число раньше, используем словарь.

## Исполнение

Для каждого числа:

1. Вычисляем число, которого не хватает до суммы `k`.

2. Проверяем, есть ли оно среди уже просмотренных элементов.

3. Если есть, возвращаем сохранённый индекс и текущий индекс.

4. Если нет, сохраняем текущий элемент и его индекс:

По условию гарантируется, что подходящая пара существует ровно одна, поэтому алгоритм обязательно найдёт её.

## Сложность

Пусть `n` — количество элементов массива.

Мы проходим по массиву один раз:

```text
O(n)
```

Для каждого элемента выполняются операции поиска и добавления в словарь.

Амортизированно поиск и вставка в хеш-таблицу выполняются за:

```text
O(1)
```

Поэтому общая временная сложность:

```text
O(n)
```

### Память

В худшем случае нужная пара может находиться в самом конце массива.

Тогда до нахождения ответа в словаре будут храниться почти все предыдущие элементы:

```text
O(n)
```

Для каждого сохранённого значения хранится его индекс, поэтому дополнительная память алгоритма:

```text
O(n)
```

## Визуализация

Возьмём

```text
arr = [8, 1, 6, 2, 9]
k = 10
```

Изначально:

```text
items_dict = {}
```

Первый элемент:

```text
i = 0
item = 8
need = 10 - 8 = 2
```

`2` в словаре нет, поэтому сохраняем:

```text
items_dict = {
    8: 0
}
```

Следующий элемент:

```text
i = 1
item = 1
need = 10 - 1 = 9
```

`9` в словаре нет:

```text
items_dict = {
    8: 0,
    1: 1
}
```

Следующий элемент:

```text
i = 2
item = 6
need = 10 - 6 = 4
```

`4` в словаре нет:

```text
items_dict = {
    8: 0,
    1: 1,
    6: 2
}
```

Следующий элемент:

```text
i = 3
item = 2
need = 10 - 2 = 8
```

`8` уже есть в словаре с индексом `0`.

Значит:

```text
arr[0] + arr[3] = 8 + 2 = 10
```

Ответ:

```text
0 3
```

Алгоритм останавливается сразу после нахождения единственной подходящей пары.
