# Hash table

## Идея

Пары «ключ–значение» хранятся в нескольких отдельных списках — корзинах.

Для каждого ключа определяется, в какую корзину он должен попасть. Если разные ключи попадают в одну и ту же корзину, возникает коллизия.

Чтобы такие элементы не потерялись, в одной корзине хранится сразу несколько пар «ключ–значение».


## Исполнение

Таблица хранится как список списков:

```text
[
    [],
    [["apple", 10], ["banana", 20]],
    [],
    [["orange", 30]]
]
```

### Вставка

1. Вычисляем индекс корзины.
2. Проверяем, есть ли такой ключ в корзине.
3. Если ключ найден, заменяем его значение.
4. Если ключа нет, добавляем новую пару `[key, value]`.

Если таблица заполнена больше чем на `75%`, увеличиваем её размер в два раза и заново распределяем элементы.

### Поиск

1. Вычисляем индекс корзины.
2. Ищем ключ внутри этой корзины.
3. Если ключ найден, возвращаем значение.
4. Если ключа нет, вызываем `KeyError`.

### Удаление

1. Вычисляем индекс корзины.
2. Ищем нужный ключ.
3. Удаляем найденную пару.
4. Уменьшаем количество элементов в таблице.

## Коллизии

Например, два разных ключа могут попасть в одну корзину:

```text
table[3] = [
    ["apple", 10],
    ["banana", 20]
]
```

При поиске сначала определяется корзина, а затем нужный ключ ищется уже внутри неё.

## Увеличение таблицы

Если:

```text
size / capacity > 0.75
```

размер таблицы увеличивается в два раза.

После этого индексы всех ключей нужно вычислить заново, потому что результат `hash(key) % capacity` зависит от `capacity`.

## Сложность

В среднем:

```text
insert  — O(1)
get     — O(1)
remove  — O(1)
```

В худшем случае, если все ключи попадут в одну корзину:

```text
O(n)
```

По памяти:

```text
O(n)
```

## Пример

Добавим элементы:

```text
insert("apple", 10)
insert("banana", 20)
insert("orange", 30)
```

Таблица может выглядеть так:

```text
0 -> []
1 -> [["orange", 30]]
2 -> []
3 -> [["apple", 10], ["banana", 20]]
4 -> []
5 -> []
6 -> []
7 -> []
```

Здесь `"apple"` и `"banana"` попали в одну корзину, поэтому возникла коллизия.

Поиск:

```text
get("banana") -> 20
```

Обновление значения:

```text
insert("banana", 100)
get("banana") -> 100
```

Удаление:

```text
remove("banana") -> 100
```

После удаления:

```text
get("banana") -> KeyError
```
