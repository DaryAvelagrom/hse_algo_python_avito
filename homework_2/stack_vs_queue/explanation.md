# Stack vs queue

## Идея

Реализовать стек и очередь на основе двусвязного списка.

Для стека используется принцип LIFO: последний добавленный элемент извлекается первым.

Для очереди используется принцип FIFO: первый добавленный элемент извлекается первым.

## Исполнение

Каждый элемент двусвязного списка хранит значение и два указателя: на предыдущий и на следующий элемент.

При добавлении нового элемента в конец списка обновляем указатель на следующий элемент у текущего последнего элемента и переносим конец списка на новый элемент. У нового элемента указатель на предыдущий элемент будет ссылаться на старый конец списка.

Также реализуем удаление элементов с начала и с конца списка так же с помощтю замены указателей у текущих конца и начала списка.

Для стека используем удаление с конца списка, поэтому последним извлекается последний добавленный элемент. Для очереди используем удаление с начала списка, поэтому первым извлекается первый добавленный элемент.

## Сложность

Все основные операции выполняются за константное время так как изместны указатели на начало и конец очереди и стека:

```text
push  — O(1)
pop   — O(1)
peek  — O(1)
```

По памяти структура занимает:

```text
O(n)
```

где `n` — количество элементов в стеке или очереди.

## Пример

Добавим элементы `1` и `2`:

```text
tail
 ↓
1 <-> 2
     ↑
    head
```

### Стек `Lifo`

Стек работает по принципу LIFO — последний добавленный элемент извлекается первым.

```text
push(1)
push(2)
pop() -> 2
push(3)
pop() -> 3
pop() -> 1
```

Состояния стека:

```text
push(1)

tail
 ↓
1
↑
head
```

```text
push(2)

tail
 ↓
1 <-> 2
     ↑
    head
```

```text
pop() -> 2

tail
 ↓
1
↑
head
```

```text
push(3)

tail
 ↓
1 <-> 3
     ↑
    head
```

Итоговый порядок извлечения:

```text
2, 3, 1
```

### Очередь `Fifo`

Очередь работает по принципу FIFO — первый добавленный элемент извлекается первым.

```text
push(1)
push(2)
pop() -> 1
push(3)
pop() -> 2
pop() -> 3
```

Состояния очереди:

```text
push(1)

tail
 ↓
1
↑
head
```

```text
push(2)

tail
 ↓
1 <-> 2
     ↑
    head
```

```text
pop() -> 1

tail
 ↓
2
↑
head
```

```text
push(3)

tail
 ↓
2 <-> 3
     ↑
    head
```

Итоговый порядок извлечения:

```text
1, 2, 3
```
