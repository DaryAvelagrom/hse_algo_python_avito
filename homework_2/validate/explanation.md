# Validate

## Идея

Будем последовательно добавлять элементы из `pushed` в стек и каждый раз проверять, совпадает ли вершина стека со следующим элементом из `popped`.

Если совпадает, извлекаем элемент из стека и переходим к следующему элементу `popped`.

## Исполнение

Создаём пустой стек и индекс `j`, который показывает, какой элемент из `popped` нужно получить следующим.

Для каждого элемента из `pushed`:

1. Добавляем его в стек.
2. Пока стек не пуст и его вершина совпадает с `popped[j]`, удаляем вершину стека.
3. Увеличиваем `j`.

После обработки всех элементов проверяем, дошёл ли `j` до конца `popped`.

Если все элементы удалось получить в нужном порядке, возвращаем:

```text
True
```

Иначе:

```text
False
```

## Сложность

Каждый элемент добавляется в стек не более одного раза и удаляется не более одного раза.

Поэтому сложность по времени:

```text
O(n)
```

где `n` — длина `pushed`.

В худшем случае в стеке могут одновременно находиться все элементы, поэтому сложность по памяти:

```text
O(n)
```

## Пример

Возьмём:

```text
pushed = [1, 2, 3, 4, 5]
popped = [1, 3, 5, 4, 2]
```

Работа алгоритма:

| Операция | Стек | Следующий элемент `popped` |
|---|---|---:|
| push(1) | [1] | 1 |
| pop() | [] | 3 |
| push(2) | [2] | 3 |
| push(3) | [2, 3] | 3 |
| pop() | [2] | 5 |
| push(4) | [2, 4] | 5 |
| push(5) | [2, 4, 5] | 5 |
| pop() | [2, 4] | 4 |
| pop() | [2] | 2 |
| pop() | [] | — |

Все элементы `popped` удалось получить в нужном порядке, поэтому ответ:

```text
True
```

Для:

```text
pushed = [1, 2, 3]
popped = [3, 1, 2]
```

получаем:

```text
push(1)
push(2)
push(3)
pop() -> 3
```

Дальше нужно получить `1`, но на вершине стека находится `2`.

Поэтому такая последовательность невозможна и ответ:

```text
False
```
