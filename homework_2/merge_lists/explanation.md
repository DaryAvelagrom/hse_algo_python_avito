# Merge lists

## Идея

Объединяем два отсортированных односвязных списка с помощью двух указателей. Они указывают на текущие элементы первого и второго списков. На каждом шаге сравниваем значения этих элементов и добавляем в результат меньший.

## Исполнение

### Вариант с временным элементом

Создаём временный элемент и указатель на последний элемент результирующего списка.

Пока оба списка не закончились:

1. Сравниваем значения текущих элементов первого и второго списка.
2. Меньший узел присоединяем к последниему элементу результирующего списка.

Когда один список заканчивается, оставшуюся часть второго списка сразу присоединяем к результату.

### Вариант без временного элемента

Сначала отдельно выбираем первый элемент результата среди первых элементов двух списков. 

После этого алгоритм работает так же:

1. Сравниваем текущие элементы двух списков.
2. Меньший присоединяем к результату.
4. После завершения одного списка присоединяем остаток второго.

В этом варианте дополнительный временный узел не создаётся.

## Сложность

Каждый узел обоих списков обрабатывается не более одного раза.

Если длины списков равны `n` и `m`, сложность по времени:

```text
O(n + m)
```

Дополнительная память:

```text
O(1)
```

Новые узлы для результирующего списка не создаются, используются узлы исходных списков.

## Пример

Даны списки:

```text
list1 = [1, 2, 4]
list2 = [1, 3, 4]
```

Сначала:

```text
cur1 = 1
cur2 = 1
```

Берём первый `1`:

```text
result = [1]
cur1 = 2
cur2 = 1
```

Теперь `1 < 2`, поэтому берём элемент из второго списка:

```text
result = [1, 1]
cur1 = 2
cur2 = 3
```

Дальше:

```text
2 < 3
```

Получаем:

```text
result = [1, 1, 2]
```

После этого:

```text
3 < 4
```

Получаем:

```text
result = [1, 1, 2, 3]
```

Остаются два элемента со значением `4`:

```text
result = [1, 1, 2, 3, 4, 4]
```

Итог:

```text
[1, 1, 2, 3, 4, 4]
```
