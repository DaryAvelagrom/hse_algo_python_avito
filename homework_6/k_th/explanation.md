# K-th

## Идея

Пусть `k` считается с единицы от максимума. Тогда в порядке возрастания
ответ стоял бы на индексе `len(nums) - k`. Повторы занимают отдельные позиции.

Quickselect выбирает случайный опорный элемент и за один проход делит
текущий отрезок на три группы. Сначала идут элементы меньше опорного,
затем равные ему, затем большие. По границам групп определяем, где
лежит нужный индекс. Если он попал в группу равных, ответ найден.
Иначе продолжаем только в нужной группе.

## Исполнение

`kth_largest(nums, k)` работает с копией массива. При разбиении
`[left, lower)` содержит меньшие элементы, `[lower, index)` содержит
равные, `[index, upper)` ещё предстоит обработать, а `[upper, right)`
содержит большие. Когда `index == upper`, границы трёх групп известны.
Все значения вне оставленного отрезка уже лежат с нужной стороны
от него, поэтому индекс можно использовать без пересчёта.

Алгоритм выполняет частичные разбиения без полной сортировки и кучи.
Если `k` выходит за диапазон от 1 до длины массива, функция выдаёт
`ValueError`.

## Визуализация

Пусть `nums = [5, 2, 4, 1, 3]` и `k = 2`. Нужен индекс `5 - 2 = 3`.
Один из возможных порядков опорных элементов при случайном выборе
показан в таблице.

| Отрезок | Опорный | Массив после разбиения | Действие |
| --- | --- | --- | --- |
| `[0, 5)` | 3 | `[2, 1, 3, 4, 5]` | Индекс 3 правее группы равных `[2, 3)`, берём `[3, 5)` |
| `[3, 5)` | 4 | `[2, 1, 3, 4, 5]` | Индекс 3 в группе равных `[3, 4)`, возвращаем 4 |

## Сложность

Ожидаемое время составляет `O(n)`. С вероятностью не меньше половины
случайный опорный попадает в среднюю половину элементов по рангу.
Тогда следующий отрезок содержит примерно не больше трёх четвертей
элементов, а суммарная работа по таким сокращениям ограничена
геометрической прогрессией. Повторы могут сузить отрезок ещё сильнее.

В худшем случае подряд выбираются крайние элементы, и время составляет
`O(n²)`. Разбиение занимает `O(1)` дополнительной памяти. С учётом копии
массива требуется `O(n)` памяти.

## Тесты

`test_k_th.py` проверяет оба примера из условия, один элемент, массив
одинаковых элементов, отрицательные числа, крайние ранги и неверные
значения `k`. Для массива с повторами проверяются все допустимые ранги.
